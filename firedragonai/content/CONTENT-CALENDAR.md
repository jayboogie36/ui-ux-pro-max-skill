# Inferno 90-Day Content Calendar

A done-for-you posting system for Inferno clients across **Instagram, Facebook & TikTok**.
The dated, ready-to-schedule version is **`content-calendar.csv`** (182 posts / 90 days) — import
it into Google Sheets, Notion, GoHighLevel, Metricool, or Later. Regenerate or re-date it anytime:

```bash
cd content && python3 make_calendar.py   # edit START_DATE / idea banks first
```

---

## The strategy: 4 content pillars on rotation
Every day leads with one pillar so the feed stays balanced — never all-promo, never all-fluff.

| Pillar | Job | Ratio |
|--------|-----|-------|
| **Educate** | Build authority, get saves/shares | ~30% |
| **Transformation / Proof** | Show results, build trust | ~25% |
| **Promote / Offer** | Drive bookings & DMs | ~20% |
| **Engage / Behind-the-scenes** | Humanize, boost reach via comments | ~25% |

**Cadence (tunable in `make_calendar.py`):** IG 5×/wk · FB 4×/wk · TikTok 5×/wk · Sat light · Sun rest.
**Format priority:** short-form **video (Reels/TikToks)** first — it's where organic reach lives.

## Repeatable weekly template
| Day | Lead pillar | Best format |
|-----|-------------|-------------|
| **Mon** | Educate | Reel + carousel — start the week with value |
| **Tue** | Transformation / Proof | Before/after, testimonial |
| **Wed** | Promote / Offer | Talking-head Reel + offer image |
| **Thu** | Engage / BTS | Day-in-the-life, poll/question |
| **Fri** | Educate | Myth-busting, quick tip |
| **Sat** | Proof / community | Review repost (light day) |
| **Sun** | Rest / Story-only | Optional behind-the-scenes Story |

## Hook formulas (the first 2 seconds win)
- "3 mistakes [audience] make with ___ (and the fix)"
- "The #1 thing nobody tells you about ___"
- "Before & after: ___"
- "POV: you finally ___"
- "Save this if you ___"
- "Watch this before you ___"

## CSV columns
`Date · Weekday · Week · Platform · Pillar · Format · Hook / Idea · Suggested CTA · Caption · Asset · Status`

**Workflow:** fill `Hook / Idea` from the niche bank → write the `Caption` (AI-assisted) → attach the
`Asset` → set `Status` to *Drafted → Scheduled → Posted*. Batch a week at a time.

> Tip: keep a 70/20/10 mix — 70% value/proof, 20% offers, 10% pure fun/trends — and let the
> Promote posts point to the client's funnel or instant-quote page.
